# 訓練你的口腔，让打鼾停止

## 口肌功能治療：針對打鼾與睡眠呼吸中止的簡單練習

# **帮助减少打鼾并改善OSA的口腔与喉部練習**

**关键要点**

- 口腔与喉部練習（又称为咽口肌肉訓練）可以改善阻塞性睡眠呼吸中止症（OSA）并减少打鼾。
- 这些練習能够強化氣道与舌頭肌肉，促进鼻呼吸。
- 每天至少練習三次，持續三个月即可见效。

打鼾常常让伴侣、室友或家人感到困擾。它会破壞睡眠，甚至可能迫使一些人分房睡。为了避免这些问题，很多人都希望能少打鼾。然而，并非所有减少打鼾的方法都有科學依據。

研究表明，对于輕度**打鼾**的人群，口腔与喉部練習可以帮助強化氣道周围的肌肉，使打鼾的频率和響度下降。同样，这些練習也被證實能改善轻到中度的阻塞性睡眠呼吸中止症（OSA）。

如同任何運動訓練，这些口腔練習也需要时间与堅持。许多轻到中度OSA患者在正确練習后，都報告打鼾减少、睡眠質量改善。

# **为什么我们会打鼾或出現阻塞性睡眠呼吸中止症？**

在睡眠中，舌頭后的空间会变窄，周圍組織变得鬆弛。当空气进出时，这些組織被氣流震動，就像风中飘动的旗帜一样发出聲音。打鼾正是由氣流使咽喉鬆弛組織振動所造成的。

阻塞性睡眠呼吸中止症则发生在咽喉后部的肌肉鬆弛到几乎或完全堵塞氣道的程度时。这会干擾睡眠，并導致睡眠期間氧氣水平下降。

# **哪些口腔練習能帮助停止打鼾？**

有多种練習可以通过特定的訓練技術強化舌頭、面部与喉部肌肉。每种練習可組合起来，每天進行两到三次。

### **舌頭練習**

![舌頭在上顎前后移动的練習示意图。](https://www.sleepfoundation.org/wp-content/uploads/2017/07/SF-23-171_MouthExercises-TongueSlide-300x120.png)

### 舌頭練習 #1：舌頭滑動

- 将舌尖放在上门牙的背面，沿着上顎慢慢向后滑動。重複5–10次。
- 有助於強化舌頭与喉部肌肉。

![舌頭向外伸展的練習示意图。](https://www.sleepfoundation.org/wp-content/uploads/2017/07/SF-23-171_MouthExercises-TongueStretch-150x150.png)

### 舌頭練習 #2：舌頭伸展

- 盡可能把舌頭伸出来，试着在抬头看天花板的同时用舌頭碰下巴。保持10–15秒，逐漸延長时间。重複5次。
- 有助於增加舌頭力量。

![舌頭向上推的練習示意图。](https://www.sleepfoundation.org/wp-content/uploads/2017/07/SF-23-171_MouthExercises-TonguePushUp-150x150.png)

### 舌頭練習 #3：舌頭向上推

- 将舌頭贴在上顎，用整条舌頭用力顶住。保持10秒，重複5次。
- 有助於增强舌頭与軟腭的力量与張力。

![舌頭向下推的練習示意图。](https://www.sleepfoundation.org/wp-content/uploads/2017/07/SF-23-171_MouthExercises-TonguePushDown-150x150.png)

### 舌頭練習 #4：舌頭向下推

- 将舌尖抵住下门牙，然后让舌根壓平贴近口腔底部。保持10秒，重複5次。
- 有助於強化舌頭与軟腭的肌肉張力。

### **面部練習**

口腔練習可調動面部肌肉，有助於防止打鼾。每天可進行多次。

### 面部練習 #1：拉颊練習

![拉颊練習示意图。](https://www.sleepfoundation.org/wp-content/uploads/2017/07/SF-23-171_MouthExercises-CheekHook-300x120.png)

- 用手指钩住右臉頰轻轻往外拉，然后用面部肌肉将臉頰拉回。每侧重複10次。
- 有助於訓練呼吸时口腔的閉合能力。

### 面部練習 #2：下顎伸展

![下顎伸展練習示意图。](https://www.sleepfoundation.org/wp-content/uploads/2017/07/SF-23-171_MouthExercises-MouthOpenClose-300x120.png)

- 嘴唇緊閉，用力抿嘴。然后张口放鬆下顎与嘴唇。重複10次。
- 有助於強化下顎、面部及喉部肌肉。

### **鼻呼吸訓練**

此練習能改善鼻呼吸，从而在睡眠中稳定氣道。

1. 闭上嘴、放鬆下顎，从鼻子吸气。  
2. 用手指堵住一侧鼻孔。  
3. 从另一侧鼻孔轻轻呼气。  
4. 每次换侧，重複约10次。  
5. 你可能会发现一侧鼻孔比另一侧更堵塞，可以重点練習那一侧。

### **發音元音**

发元音会調動喉部肌肉，有助於強化它们。

1. 重複发出 *a-e-i-o-u*。  
2. 先正常發音，再拉长或加快節奏。  
3. 每个音重複10至20次，再换下一个音。  
4. 也可組合音（如 ooo-aaah）重複練習。

### **唱歌練習**

唱歌能激活口腔与喉部的多种肌肉，并涉及不同元音。初步研究发现，专注的唱歌訓練可减少打鼾。  
**Scientific Research Publishing (SCRIP)** 是最大的开放获取期刊出版机构之一，出版200多种同行评审學術期刊。  
唱歌时应专注于重複、用力地发出特定音节，而不仅仅是唱歌词。

# **口腔練習如何帮助减少打鼾与睡眠呼吸中止症？**

口腔練習也称为“口肌功能訓練”（Myofunctional Therapy）或“咽口練習”（Oropharyngeal Exercises）。  
由专业治療师指导时，它能強化氣道与舌頭肌肉，并促进鼻呼吸。咽口部位包括舌后部、喉侧、扁桃体、腺样体与軟腭（口腔顶部的柔软部分）。

研究发现，清醒时反复進行这些咽口練習，可防止組織在睡眠中过度鬆弛与震動。多项研究證實，強化这些肌肉可减少打鼾及輕度阻塞性睡眠呼吸中止症。

### **哪些人适合進行口腔与喉部練習？**

研究显示，这些練習对打鼾者及轻到中度OSA患者最为有效。  
OSA患者若同时配合 **CPAP机器** 或术后康复練習，效果更好。

需要注意的是，即使是輕度打鼾，口腔練習也并非对所有人有效。个体的口腔、舌頭、喉部结构差异都会影响效果。

如果打鼾与**饮酒**或鎮靜劑引起的肌肉放鬆有关，则效果可能有限。

### **練習频率与时长**

根据研究，要想减少打鼾或OSA，建議每天至少練習10分钟，堅持三个月。  
大多数人每天練習2–3次。

多数研究显示，**3个月**后能观察到明显改善。  
另一项研究指出，使用智能手机游戏進行口腔練習，每天15分钟以上，同样能改善打鼾。

就像健身一样，肌肉強化需要时间，别期望一夜见效。  
这些練習不需任何器材，可随时随地進行。长期堅持将增强氣道肌肉，减少阻塞風險。

### **副作用与風險**

有些人可能觉得这些練習枯燥或滑稽，但几乎没有生理副作用。

若以此取代医生处方的打鼾或睡眠呼吸中止症治療，才可能带来健康風險。  
建議在开始或停止任何治療前，先諮詢医生。

这些口腔練習与言语治療中的訓練类似。如需专业指导，可向医生諮詢言语治療师或相关专家。

# **何时应就醫？**

部分打鼾可能是阻塞性睡眠呼吸中止症的信號，若未及时診斷与治療，可能引发嚴重健康问题。

若出現以下風險因素，应及时就醫：

- 打鼾时伴随喘氣、窒息或哽咽声  
- 白天明显嗜睡或疲劳  
- 情緒波动、思維迟缓、注意力下降  
- 早晨头痛  
- 高血壓  
- 肥胖或體重近期上升  

虽然口腔練習是有前景的家庭療法，但并非万能。  
在必要时应与医生推荐的其他治療结合使用。  
许多打鼾者通过使用止鼾牙套获得改善，这类裝置可前移下顎或固定舌頭，帮助氣流順暢、减少打鼾。
